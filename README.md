# AI Engineer Roadmap — 6-Month Day-Wise Plan

A structured, day-by-day roadmap to go from beginner to job-ready **AI Engineer**, with a specialization in **AI-powered QA/Testing tools**.

- **File:** `AI_Engineer_6Month_DayWise_Roadmap.xlsx`
- **Start Date:** 27 July 2026 (Monday)
- **End Date:** 9 January 2027
- **Duration:** 24 weeks (~6 months), 3-4 hrs/day, 6 days/week (Sunday off)
- **Total tracked working days:** 144

## Core Rule

Every project in this roadmap must be built using **only the concepts learned up to that point** — no jumping ahead to libraries or techniques not yet covered. This forces real understanding instead of copy-pasted tutorials.

## Workbook Structure

| Sheet | Purpose |
|---|---|
| **Overview** | High-level snapshot: dates, phases, daily commitment, how to use the workbook |
| **Daily Plan** | Main tracker — one row per working day with exact date, week, phase, topic to learn, coding task, and a Status dropdown (Not Started / In Progress / Done / Skipped) |
| **Milestone Projects** | The 6 checkpoint/capstone projects, each listing exactly which concepts are allowed at that stage |
| **Weekly Summary** | Bird's-eye view of all 24 weeks — dates, phase, topic, milestone flag |
| **Resources** | Tools/frameworks mapped to each phase, including the AI-testing specialization stack |

## Phases

1. **Weeks 1–6 — Foundations:** Python, OOP, Git/Linux, Linear Algebra, Calculus, Probability, DSA
2. **Weeks 7–12 — Data Science & ML Core:** Pandas/NumPy, EDA, Supervised & Unsupervised ML, Deep Learning (ANN/CNN/RNN)
3. **Weeks 13–17 — NLP, LLMs & GenAI:** NLP fundamentals, LLM concepts, Vector DBs, LangChain/LangGraph, RAG, AI Agents, GANs
4. **Weeks 18–20 — AI-for-QA/Testing Specialization:** Docker, FastAPI, Playwright, AI-driven test case & bug report generation
5. **Weeks 21–24 — Capstone, Deployment & Job Prep:** Cloud deployment, capstone project, portfolio polish, job applications

## Milestone Projects

| Week | Project | Concepts Allowed |
|---|---|---|
| 6 | Smart Inventory/Contact Manager (CLI) | Python + OOP + DSA only |

| 22 | Capstone: Fake News/Bot Detector OR GAN Art Generator | All cumulative concepts |

## How to Use

1. Open the **Daily Plan** sheet and start from today's row.
2. Read the "Learn + Code Task" for the day, complete both the learning and the coding part.
3. Update the **Status** dropdown as you progress.
4. When you hit a milestone week, check the **Milestone Projects** sheet for the exact scope and allowed-concepts constraint before starting.
5. Use the **Resources** sheet to find the right tool/framework for each topic as it comes up.
6. Push every project's code to GitHub as you complete it — this becomes your portfolio.

## Notes

- Daily commitment assumes 3–4 focused hours; adjust pacing if you can dedicate more or less time, but try to preserve the "cumulative concepts only" rule for projects.
- Sundays are kept free by design — use them for rest or catch-up if a day slips.
